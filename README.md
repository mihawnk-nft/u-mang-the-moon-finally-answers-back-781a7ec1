Entry for the [make.fun](https://make.fun/c/u-mang-the-moon-finally-answers-back-781a7ec1) competition **"The Moon Finally Answers Back"**.

## What it does

`main.py` (pure Python standard library, no dependencies) writes one line —
1 to 240 characters — in the voice of the Moon replying at last to the
wishes, howls and late-night promises of everyone staring up at it, to
`/output/entry.txt`:

> Every wish, every howl, every 'I'll change, I swear' at 2 a.m. -- I heard them all. Four billion years, and not one of you ever wished me anything back.

## Run it

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py out.txt    # write to a custom path (local testing)
```
